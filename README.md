# Сравнение вакансий программистов
Сравнение зарплат программистов на всех популярных языках программирования, взятая с двух платформ: Head Hunter и SuperJob
  
## Как установить
python 3.10+ уже должен быть установлен на вашем компьютере.

1. Скачиваем репозиторий на свой компьютер
2. Для установки зависимостей заходим в терминал и пишем:
 ```
pip install requirements.txt
```
3. Для работы скрипта вам понадобится ключ от SuperJob. Переходим на оффициальный сайт в раздел для разработчиков и получаем его: https://api.superjob.ru/?ysclid=mp2zpv5dmf172441743
4. Создаем файл .env и прописываем нашу переменную окружения таким образом: ```SECRET_KEY==Ваш ключ```


## Запуск 

 Переходим в терминал и пишем:
 ```
python main.py
```                              
Скрипт покажет таблицу со сравнением зарплат на разных языках программирования в виде таблицы, а так же примерную зарплату

## Подробнее:
Скрипт сравнивает зарплаты путем сравнения двух строк: 
- От
- До

Для понимания:

- Если указана только строка 'от', то умножаем на 0.8
- Если указана только строка 'до' то умножаем на 1.2
- Если есть оба поля, скрипт считает примерную зарплату, путем сложения двух полей и разделением на 2
